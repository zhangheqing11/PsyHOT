# 从公众号报道补收原论文

公众号报道已公开入库，并不保证期刊原论文存在。后台每十分钟扫描至多二十篇近三十天新发现、已通过预筛并公开的学界/混合公众号文章；每篇保留至多八条引用，每轮核验至多十条。扫描记录绑定正文版本，正文修订后旧关联立即隐藏，再按新版本确认。

支持正文 DOI（保留合法括号）、常见出版商 DOI 链接、Nature 文章链接、ScienceDirect PII、明确标注的原题及 APA 式书目题名；已知出版商链接的题名也可作为检索线索。优先处理“论文信息／原文信息／文献来源／文献索引”中的标识。没有清晰题名或标识的泛化中文新闻标题暂不自动推测；题名必须在 Crossref 中唯一且规范化后完全一致。非期刊论文、歧义和未找到都不自动入库。

只向既有的免费 Crossref、Europe PMC、OpenAlex 接口发送学术标识或题名，不直接抓取公众号给出的任意链接。元数据接口通过现有受保护网络读取层访问。匹配 DOI 后补充已识别的摘要和正式发表日；只有年月时不伪造具体发表日。已存摘要的质量边界与站内既有规则一致。

DOI 注册表以及出版商 PII 别名确保多篇报道、并发补收和后来常规期刊采集复用同一条目。已有论文也会按 DOI、出版商地址或唯一规范题名查找，处理 Lancet 栏目标题前缀和 PII 地址。如果已有条目缺摘要，会补齐并重新进入常规处理；已有完整论文直接关联，不重跑其模型判断。

原论文通过 `upsertMaterial` 入库并按补收归档，保留实际发表日；没有精确日期时保留未知。仍执行现行预筛、评分、写作、发布、摘要翻译和预算规则，不因被公众号引用就直接进精选。补收不触发新内容推送；历史论文不增加当前事件热度。只读者打开页面不会触发抓取或模型请求。

优先复用同名、期刊标签的一手信源；已暂停信源不会被新建入口绕过。未接入期刊仅建立 `external` 按需补收入口，标为“引用补收”，并不自动订阅整本期刊。默认不展示、分发全文。持续采集一本新期刊仍由独立信源配置决定。

引用关系保存于 `paper_references`，并在报道详情显示“报道引用的论文”，在论文详情显示“相关报道”。这些是引用关系，不会把一篇报道提及的不同研究强制合为同一事件。公开链接通过统一 publication 读取层，只显示已公开、过发布门槛且可进入内容池的条目；撤回、隔离、未处理、旧版本关系不展示。

未找到和临时错误留存状态与错误文本，最多五次核验，前四次失败分别按 6/24/72/168 小时退避，达到次数上限后保留失败状态。进程中断的核验十五分钟后重新可领。已暂停期刊每天再看一次，不消耗失败次数。

## 开关与上线

增量迁移：`0064_paper_references.sql`；新任务：`content.paper-backfill`，随现有 worker 调度。

- `COLLECT_ENABLED=false`：不执行自动补收。
- `PAPER_BACKFILL_ENABLED=false`：仅停用本机制。
- 所有付费分析继续经过现有回执与全站预算；免费元数据查询有数量、大小和超时上限。
- 初始窗口只覆盖近三十天发现的合格公众号报道，不对全站历史做无限回溯，不沿原论文参考文献递归抓取。

## 验证

本地隔离 PostgreSQL 和 HTTP 替身覆盖解析、题名歧义、错误 DOI、PII 别名、并发去重、已有条目补摘要、历史日期、修订、重试、暂停与关闭开关、双向公开边界。独立免费接口核验中，上轮九篇真实报道全部识别到原论文，并获取到匹配 DOI 的摘要与完整发表日。站内原论文和报道双向跳转已在本地实际浏览器验证。
