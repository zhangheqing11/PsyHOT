页首说明：

> 本站聚合心理学与精神医学的公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。内容只用于了解领域进展，不构成诊断或治疗建议。网站、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 不构成诊疗建议

本站汇总的是心理学与精神医学的研究和行业动态，面向专业读者，只用于了解领域进展。站内内容不构成医疗、诊断、心理咨询或治疗建议，也不能替代专业人员的评估；单项研究的结论有其样本和适用范围，请以原文和专业人员的判断为准。

如果你或身边的人正处于危机中，请立即拨打 120 或 110，或拨打全国统一心理援助热线 12356（由国家卫生健康委员会设立，各地接听时间不同，原则上每天不少于 18 小时）。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 4. 使用本站的数据

请写明你允许的用途（例如个人阅读、组织内部使用），以及需要事先取得你同意的用途（例如商业产品、公开转载、批量再分发）。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。
