
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：研究对象与发现 / 疗法或药物名 / 量表名 / 机构名 / 政策名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是文学化的短语 / 问句 / 没信息量的 teaser（如 "The quiet cost"、"Rethinking the mind"、"重磅研究"）时，结合【来源】和正文把研究对象和发现补进标题。例：原标题 "The quiet cost" + 正文是一项关于照护者孤独感的队列研究 → "队列研究发现长期照护者的孤独感明显更高"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体研究机构、样本或数字时，用上位词（如“一项大样本研究”）兜底，绝不凭“领域常识”编一个机构、期刊、样本量或效应量。
5. 原标题表达的【文章类型和结论强度】是硬边界：How / Why / Review / Commentary / Perspective 这类解释、综述、评论标题，中文标题必须保留这个类型；不能因为正文谈到某项研究或新数据，就改写成“研究发现 / 证实 / 首次揭示”。原标题说 "linked to" / "associated with"，中文只能写“与……有关”，不能写成“导致 / 引发 / 让人……”。只有原标题明确宣布了批准、发布、生效，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的研究对象、疗法或机构名。
   例：原标题 "Social media use linked to poorer sleep in adolescents" → “青少年社交媒体使用与睡眠变差有关”，不能写成“社交媒体让青少年睡不好”。
   例：原标题 "Why therapy works for some and not others" + 正文讨论的是抑郁的心理治疗 → “为什么抑郁的心理治疗对有些人有效、对另一些人无效”，不能写成“研究揭示心理治疗无效的原因”。
