# 公众号引用论文自动补收与期刊评估

基于 main e80f289；用户已授权实现自动补收并要求用数据测试评估期刊价值。实现与评估在本地完成，生产发布与常规期刊接入保留为可审核结果。

## 成功条件

- 扫描已公开且预筛通过的公众号正文，识别 DOI、受支持的出版商论文链接、明确标注或书目格式的原论文题名；有歧义的题名不自动采信。
- 用 Crossref 已有公开接口核实元数据，沿用现有摘要补全、材料身份、时间归档、分析、发布和预算链；不沿引用递归扩张，不将所有参考文献强行合为同一事件。
- 持久保存报道到原论文的引用关系；详情页双向展示已有公开论文与相关报道，撤回或未公开内容不泄露。
- 相同 DOI 的并发/多报道发现只存一篇；记录找不到、错误与重试；限制每次扫描/解析数量，并遵守 COLLECT_ENABLED。
- 题名识别、元数据确认、已有条目复用、旧论文归档、重新扫描、重试和公开关联都由隔离测试证明。
- 对 6 本未接入期刊及 2 本已接入对照期刊取连续近期样本，分别报告采集可用性、预筛通过、现行评分入选及无法评价的内容；不将抽样命中率当全刊保证。

## 实现约束

Node 26 / TypeScript / PostgreSQL / pg-boss；无新依赖；第三方正文不直接作为可信原论文，正文版权规则不变。DOI/题名只发给已有免费学术元数据接口，禁止任意引用链接触发内网请求。新论文继续使用现有评分标准，测试只访问本机替身。

## 顺序

1. 明确引用识别和身份核验，用失败测试覆盖误匹配与恶意链接，再实现解析器。
2. 增量迁移和限量后台任务，完成补收入库、去重、失败重试和引用关系。
3. 公开读取层和详情页双向链接；关联只显示可公开内容。
4. 当前规则小样本期刊评估；保存采集原始结果与运行参数。
5. 类型检查、完整隔离测试、网页构建/测试和运行检查；复核差异并提交可审核分支。
